# Burstiness gate patterns (detail file for MEMORY.md index)

## "That's the [X]" / "That's why [X]" repeated openers
2026-07-13 — drafter frequently opens sentences with "That's the [X]" / "That's why [X]" as a summarizing connective (seen ~8-10x in a single ~1800-word post, e.g. "How I Automate Blog Writing With AI Agents"). Each instance reads fine in isolation and instances are spread across sections, not consecutive, so it does NOT trigger the burstiness gate (which requires 3+ *consecutive* same-shape sentences). Treat as elevation (vary 1-2 instances), not gate, unless an actual run of 3+ consecutive sentences sharing the construction appears. Follow-up 2026-07-14: next draft dropped to 3 instances, spread across sections — confirms elevation-only at low counts.

## Category-noun + colon + list triad
2026-07-14 — real gate pattern: three consecutive sentences each shaped "[category noun] + verb-phrase-with-a-count + colon + list," e.g. "Five of them check the piece structurally: [list]. Craft gets five more: [list]. Integrity underneath all of it gets the last five: [list]." Word counts can vary (9/13/16) and still fail — it's the identical clause shape across 3+ sentences that trips it, not raw length uniformity. Fix: merge two of the three into one sentence with em-dash asides so only 2 remain in a row.
Regression history ("automate-blog-writing-with-ai-agents", reviewer-roster paragraph): fixed once (confirmed 2026-07-14), then regressed on a later draft (2026-07-14) back to three straight colon-list sentences, regressed AGAIN on yet another draft (2026-07-15): "Five of them grade the piece as a whole... Five more grade craft... The last five sit underneath everything else...". **Confirmed-fixed is not permanent** — recheck this exact spot on every draft of this post; it's the one that keeps sliding back.

## Explicit per-beat sentence-count directive not enforced
2026-07-16 (draft mode, "rate-limiting-an-llm-so-a-stranger-cant-run-up-my-bill") — when `gateGuidance` states a literal count ("Keep the scope note to two plain sentences"), check the actual sentence boundaries in the corresponding draft prose, not just topic coverage. Draft rendered the scope note as three sentences (earlier-post recap + two separate "This one covers..."/"It also covers..." sentences) instead of the outline's intended two. Gate it; fix by merging the trailing pair with "plus" or "and" rather than a period.
Regressed AGAIN later the same day, same post, same spot: a subsequent draft (after an interim round reportedly fixed it — see MEMORY.md's now-corrected reference-passes note) shipped the scope note as three sentences again — "...covered how the assistant behaves: third person, defers instead of guessing. It also resists prompt injection. This one covers..." Fix by folding "It also resists prompt injection." into the first sentence as a third list item ("...defers instead of guessing, and resists prompt injection.") so exactly two sentences remain. This exact beat is a repeat offender — recheck the literal sentence count on every draft of this post, don't trust a prior round's "fixed" note.

## Demonstrative-pronoun-opener runs
2026-07-14 — 3+ consecutive sentences each opening on a bare demonstrative-pronoun subject ("That's...", "It...", "The two [noun]...", "This one...") in the 13-20 word range reads as monotonous even though word counts aren't identical and topics differ — the repeated pronoun-opener is the tell, not raw length. Fix: break one instance into a short fragment (e.g. "Not this one.") rather than trying to vary length alone.

## Short-uniform sentence runs (hooks and CTAs)
2026-07-14 — burstiness gate also fails in the opposite direction from "15-25 word uniform": a run of 3+ consecutive sentences that are all SHORT and similarly sized (6-10 words each) with no long run-up sentence nearby is just as flat, especially in a hook. Seen in "automate-blog-writing-with-ai-agents": six straight sentences at 9/8/9/10/6/6 words opening the post. Fix: combine adjacent short sentences with "and" for a long-short contrast (check the outline's own hook field first — it often already models the fix).
2026-07-15 (draft mode, "writing-alt-text-seo-accessibility") — same pattern recurs in CTA/instructional beats as a run of imperatives: "Pick any image, right-click it, and inspect it. Cover up the picture and read the alt attribute out loud. Judge whether it holds up as a description on its own." — three consecutive imperatives at 8/11/11 words, same verb-object-modifier shape. Fix: merge the first two via colon/and-chain, leave the last short as the punch (e.g. "pick any image, right-click it, inspect it, and cover the picture while you read the alt attribute out loud. Judge whether it holds up as a description on its own."). Watch for this shape in any "here's the test, try this on your own X" CTA — natural spot for a drafter to default to list-of-imperatives cadence. Follow-up 2026-07-15 (next draft, same post): fixed exactly as prescribed — CTA now reads "pick any image, right-click it, inspect it, and cover the picture while you read the alt attribute out loud. Judge whether it holds up as a description on its own." Confirms the merge-then-punch fix holds.
Regression 2026-07-15 (later draft, same post): slid partway back — "pick any image, right-click it, inspect it. Cover the picture, then read the alt attribute out loud. Judge whether it holds up as a description on its own." Two consecutive short imperatives (10/11 words) remain, just short of the 3+ gate threshold, so treated as elevation not gate this round — but this is the third time this exact CTA has moved on this spot. Keep prescribing the merge-then-punch fix and watch for it crossing back to 3 consecutive.

## Color-chip / design-token triad
2026-07-15 (draft mode, "dark-dashboard-design") — three consecutive sentences each following "[color-chip noun] + present-tense verb + hex/prep-phrase, + modifying clause" — e.g. "Background sits at #0c0e12, a matte charcoal a step above true black." / "Panels rest on a slightly lighter #13161c, lifting them off the base without turning shiny." / "Text runs a warm off-white, not stark white, because full white against full black is the pairing that tires eyes fastest." Word counts (12/15/21) varied but clause shape repeats 3x — common in beats that walk a list of design tokens one per sentence. Fix: turn one instance into a colon-fragment (e.g. "Panels: a slightly lighter #13161c, just enough to lift off the base without turning shiny."). Follow-up 2026-07-15 (next draft): fixed exactly as prescribed — confirms the colon-fragment fix holds across drafts.

## Fact-dense explainer paragraph with zero fragment breaks
2026-07-15 (draft mode, "design-system-with-css-variables") — a paragraph can have strong specifics and a held opinion and still gate on burstiness if every sentence lands 14-30 words with no true fragment anywhere in the run. Seen 4x in one draft: the color-drift paragraph (beat 2, 5 sentences 18-24 words), the three-typefaces paragraph (beat 6, 7 sentences 14-22 words after one short opener), the chart-series-colors paragraph (beat 8, ~7 sentences 14-32 words, zero fragments across ~200 words), and the visual-signature paragraph (beat 9, 7 sentences 13-30 words). Content quality doesn't inoculate against this — token/color/font walk-through beats are the recurring shape where a drafter defaults to uniform mid-length declarative sentences. Fix is minimal, not a rewrite: split one sentence in the run into two (or insert a 2-4 word fragment) near the top or the close of the paragraph; don't touch the specifics. Recheck this exact pattern (fact-walkthrough paragraphs with no fragment) on every draft of this post.

## Model+verb+location-clause triad survives an explicit anti-triad gateGuidance
2026-07-15 (draft mode, "which-claude-model-to-use") — the outline's own gateGuidance for the payoff beat said "phrased outside a tidy parallel triad," and the draft still shipped one: "Opus sits at the front, where a bad call cascades into everything built after it. Haiku sits near the end, where the only question is whether an answer is checkable. Sonnet fills every job between those two, including the one that once caught what Haiku missed." — three consecutive sentences, 15/15/16 words, identical [Model] + verb + location-clause + relative-clause shape. Payoff/summary beats that recap a 3-item routing table are a natural spot for a drafter to default to this shape even when explicitly warned off it. Fix: merge two of the three into one sentence (comma/and, no em-dash) so only one stands alone. Recheck this exact beat if this post is redrafted.
Follow-up 2026-07-15 (next draft, same post): fixed as prescribed — now reads "Opus sits at the front, where a bad call cascades into everything built after it, and Haiku closes it out near the back, where the only question is whether an answer is checkable. Sonnet fills everything in between, including the one call that once caught what Haiku missed." Two sentences (Opus+Haiku merged via "and", Sonnet separate with a differently-shaped clause: "including..." not "where..."). Confirms the merge-two-of-three fix holds; do not re-flag this beat unless it reverts to 3 uniform sentences.

## Drafter splits an outline's single flowing list-hook into matched short echo sentences
2026-07-15 (draft mode, "ai-automation-stack") — the outline's hook was one sentence with a four-item asyndeton list ("...twelve pipeline stages write it, a script schedules it, a 60-second deploy ships it, and a scorecard grades it."), where the repetition reads as an intentional listing device. The draft split it into two sentences of two matched clauses each: "After that, twelve pipeline stages write it, and a script schedules it. A 60-second deploy ships it, and a scorecard grades it." — both now identically shaped "[subject] [verb] it, and [subject] [verb] it," which makes the echo more noticeable than the single-sentence list did, right in the hook. Gate it (highest-visibility spot); fix is usually just restoring the outline's own single-sentence list rather than re-splitting it.
Regression 2026-07-15 (later draft, same post): reverted to a different but related split — "...a script schedules it, then a 60-second deploy ships it. A scorecard grades whatever came out the other end." The last list item got pulled into its own sentence and reworded ("grades whatever came out the other end" instead of "grades it"), breaking the asyndeton again. This exact hook keeps sliding off the outline's single-sentence list — recheck it on every draft of this post, same as the reviewer-roster colon-list spot.
Regression 2026-07-15 (yet another later draft, same post): reverted to the FIRST-documented split form again — "After that, twelve pipeline stages write the post, and a script schedules it. A 60-second deploy ships it, and a scorecard grades it afterward." The hook is oscillating between the two known failure shapes (matched-clause-pair vs. pulled-out-last-item) rather than converging on the outline's single flowing sentence — keep prescribing "restore the outline's one-sentence asyndeton list" regardless of which variant shows up.
The numeral-opener + colon-explanation triad also generalizes beyond "category noun": this draft's content-layer beat ran "Twelve stages, in that order, each handed off complete before the next one starts: [tag]. Nine of the twelve get handed to a narrow AI agent: one job each, nothing more. Three never go through an agent at all: [explanation]." — three consecutive sentences opening on a number-word (Twelve/Nine/Three) each closing on a colon-explanation, word counts varied (22/15/27) same as the original pattern. Same fix: merge two of the three so only one stands alone.

## Repeated predicate-frame echo across non-adjacent ourTakes (outline mode)

## Long qualifier-stacked sentence burying a personal detail
2026-07-15 (draft mode, "grill-me-what-an-auditor-sees") — a single very long sentence (~60-70 words) stacking a stat comparison against a second source's stat with multiple "not X, but Y" qualifiers can bury a genuine personal/opinion detail mid-sentence — e.g. "...had crossed our own malicious-intent threshold, a number I wrote up myself, close to Snyk's 76-out-of-3,984 confirmed-malicious rate, not its 36.82% any-flaw figure." "a number I wrote up myself" is exactly the held, personal detail this axis protects, drowned by three stacked qualifier clauses. This project compares its own stats to Snyk/Mitiga stats often (recurring "our number vs. their number" beat shape) — watch for this overload shape recurring in multi-source stat comparisons. Fix: split into 2-3 shorter sentences so the personal clause gets its own sentence boundary. Follow-up 2026-07-15 (next draft): fixed exactly as prescribed — confirms the split-sentence fix holds.
