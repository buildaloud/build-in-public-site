# Outline-mode axis learnings (detail file for MEMORY.md index)

## rendersAsProse: false hiding the only copy of fact-dense content
2026-07-15 (outline mode, "dark-dashboard-design", then recurred elsewhere) — `rendersAsProse: false` means the beat is skipped entirely, never shown as prose or a list (per `.claude/agents/drafter.md`: "not to appear on the page"). If a `false` beat is the ONLY place a fact-dense update lives, that's a gate-worthy voice finding, not a structural nit to defer to outline-structure-reviewer — it guarantees zero concrete specifics from that beat ever reach the reader. Check every `rendersAsProse: false` node for whether its facts/ourTake are duplicated in a rendering neighbor before accepting `false`; if not, flag it to flip to `true`.
Instances:
- "dark-dashboard-design": a "charts are new as of this date" beat with exact hex codes/chart-type inventory, nowhere else in the outline. Flagged; next draft had every beat `true` — held.
- "grill-me-what-an-auditor-sees": THREE consecutive beats (orders 3/4/5) all `false`, together carrying the entire evidentiary core (JSON score schema, the 0/35/85/4.6 scores called "centerpiece evidence," the four findings that earned the 85). Quick tell: each beat's own `gateGuidance` said it "render[s] as a short list" — a direct self-contradiction with `false`'s semantics; that contradiction alone is enough to flag without further digging. Flagged all three; confirmed fixed on next pass (all 8 beats `true`). This outline is a strong reference example otherwise: exact numbers throughout (200k downloads, 3,984/36.82%/76, 0/35/85/4.6, AST-01/AST-02).
- "automate-blog-writing-with-ai-agents": recurred a 3rd time — the order-3 "twelve stages" beat was the only place the full ordered list lived, its own `audienceNote`/`intendedBeat` explicitly described a rendered list, yet marked `false`. Same self-contradiction tell. Flagged; held fixed across two subsequent outline passes (now order 2, `true`), and that outline's `ourTake`/`facts` fields are consistently dense with exact numbers (12 stages, 15 reviewers, 42/35/2000, 90.2%, 80.9%, 39-70%, 4x/15x, 83%, gate threshold 15) — zero gate findings across the last two checks. Persistent soft spot (elevation only, not gate): order 10 "Why narrow beats mega" — its `ourTake` is the weakest opinion in the outline, closer to a neutral analogy-restatement than a held stake, but still names a specific comparative claim so stays elevation-only.

**Rule of thumb**: treat "beat instructs a list/rendered structure in its own audienceNote or intendedBeat" as an automatic cross-check against that beat's `rendersAsProse` value, every outline review, no exceptions — this is now a 3-for-3 recurring pattern across distinct posts.

**Non-failure counter-example**: `rendersAsProse: false` on a beat whose `gateGuidance` explicitly calls for a fenced code block ("Renders as a fenced css/json/etc code block with short prose before and after") is correct, not the self-contradiction tell above — a code block is a legitimate non-prose rendering, distinct from the "skipped entirely" failure mode. Seen: "design-system-with-css-variables" order-4 beat (real token names/hexes, `rendersAsProse: false`, gateGuidance says "Renders as a fenced css code block") — not flagged, outline otherwise a clean pass (2026-07-15).

## Uniform two-sentence ourTake shape across nearly every beat (elevation, not gate)
2026-07-15 (outline mode, "which-claude-model-to-use") — an outline can pass cleanly on real-opinion/concrete-specifics/human-intent per beat (zero gate findings) while every single `ourTake` still runs the identical claim-then-consequence, two-sentence shape (11 of 11 beats here). That sameness is invisible at the per-beat check this reviewer runs but is exactly the seed of drafted burstiness flattening (see burstiness-patterns.md's "same-shape sentence run" gate) if the drafter renders each `ourTake` near-verbatim. Treat as an elevation: point it out and suggest one gateGuidance line telling the drafter to vary render length beat to beat (some as one sharp line, others run out longer) — don't gate the outline itself for it, since the outline text isn't the reader-facing prose.
Follow-up 2026-07-15 (draft mode, same post): the predicted flattening mostly did NOT happen — most beats varied ourTake length/shape well in prose (short kickers, honest-limit fragments, protected verbatim lines intact). The one place a same-shape triad actually shipped was the payoff/summary beat recapping the 3-tier routing table, not the per-beat ourTakes themselves — see burstiness-patterns.md's new "Model+verb+location-clause triad" entry. The elevation-only call on the outline was correct; the real risk in this shape turned out to be the closing recap, not the individual beats.
Recurrence 2026-07-15 (outline mode, "automate-blog-publishing-schedule"): same shape again, 7 of 9 ourTakes. Otherwise a clean-pass outline — every ourTake a genuine held opinion, every facts block carrying exact numbers (220 lines, four weeks, 19/28-day coverage, twenty-minutes-to-under-a-second), no hedge theater. Kept elevation-only per the rule above; illustrated the fix on one beat rather than gating.

## A gateGuidance ban on one beat doesn't cover the same pattern unguarded in another beat's ourTake
2026-07-16 (outline mode, "teaching-a-robot-to-balance-my-game") — one beat's `gateGuidance` explicitly banned the near-banned "whole X" rhetorical-flourish family (e.g. "the whole reason") and told the drafter to state the replaced thing positively instead. A different, later beat's own `ourTake` then used the same family unguarded: "A deterministic tick you can run without a screen is the whole enabling decision; everything else in this post falls out of it." Corporate-jargon flavor ("enabling decision") compounds it — reads like keynote-speak, not Scout's plain register. Gate it: check every `ourTake`/`flare`/`point` field against bans stated elsewhere in the SAME outline's gateGuidance, not just the beat carrying the ban — a pattern one beat is told to avoid can leak into a sibling beat that has no such warning.

## Honest-limit/aside texture can live inside a differently-tagged formula
2026-07-15 (outline mode, "dark-dashboard-design") — a beat can carry real honest-limit/aside texture inside its `ourTake` prose (a first-person admission, a self-aware "I know this sounds petty" aside) even when its `paragraphFormula` is labeled `claim-then-evidence` or `show-the-work`, not `honest-limit`/`aside`. Don't gate an outline just because no beat is formula-tagged `honest-limit` or `aside` per `references/paragraph-formulas.md`'s "post with none reads like docs" warning — check whether the texture already lives inside another formula's `ourTake` text first (seen: petty-precision admission in a `claim-then-evidence` typography beat, self-doubt admission in a `claim-then-evidence` empty-state beat). Missing formula tags with texture present is an elevation, not a gate.
