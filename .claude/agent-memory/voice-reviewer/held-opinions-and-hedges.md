# Held-opinion / hedge-theater gate patterns (detail file for MEMORY.md index)

## Land the feeling and the fact in one sentence
2026-07-14 — when an outline's `ourTake`/`gateGuidance` explicitly instructs "land the feeling and the fact in the same sentence" (e.g. token-bill honest-limit beat: "I pay that bill" + the 4x/15x figures), check whether the draft literally split them into two sentences with a period — that's gate-worthy even though each sentence reads fine alone; the held opinion floats free of its evidence instead of landing in one breath. Check outline gate guidance line-by-line against actual sentence boundaries in draft mode, not just for content presence.
Regression history ("automate-blog-writing-with-ai-agents", token-bill line): fixed 2026-07-14 ("I pay that bill on every post" landed with the 4x/15x figures via "and"). Regressed on a later draft (split back into its own sentence). Fixed again on a subsequent draft via colon join ("and I pay that 15x bill on every post: real money in compute, still cheaper than shipping something broken."). Held twice in a row as of 2026-07-15 but keep checking every draft — this spot slides.

## First-person admission demoted to third person/passive
2026-07-14 — when an outline's `ourTake` states an admission in first person ("I let a build-in-public blog run with a stale description..."), watch for the drafter demoting it to third-person/passive framing that drops the "I" — the fact survives but the owned-admission voice doesn't. Flag and restore the first-person subject.
Regression history ("automate-blog-writing-with-ai-agents" opener): held correctly 2026-07-14 ("Fitting, in an uncomfortable way: I let a build-in-public blog run on a stale description of its own machine,"). Regressed 2026-07-15 on TWO fronts at once: (1) opener reverted to third person, AND (2) the reverted opener now duplicates the protected verbatim closer's exact clause ("stale description of its own machine") near-verbatim in the same short paragraph — a second, distinct failure (redundant self-repeated phrase) stacked on the first-person loss. Fix pattern: restore first person AND reword the opener so it doesn't reuse the clause reserved for the protected closer — e.g. "Fitting, in an uncomfortable way: I let this exact post run for months describing a machine that no longer existed." Check both facets (person + non-duplication) every draft, this beat keeps sliding.

2026-07-14 — add "Worth being precise about [X]:" to the recognized hedge-theater family alongside "it's worth noting" — same throat-clearing-before-the-real-claim shape. Cut the frame, state the claim that follows the colon directly.

## Vague meta-reference replacing a specific personal-stake callback
2026-07-14 — when an outline `ourTake`/`intendedBeat` gives a specific personal-stake callback (e.g. "it's why I get to touch the draft least of anyone and still trust what ships," echoing the post's own opening line), watch for the drafter swapping it for a vague meta-reference that names no real claim (seen: "It's the same math as the hook."). Reads as filler, not an opinion — flag even though grammatically fine, restore language close to the outline's own callback.
Recurred 2026-07-16 (draft mode, "dividing-a-company-that-makes-no-money", honest-limit beat) as a number-drop, not just a claim-drop: outline's `intendedBeat` specified a closing comparison line — "Turns out guessing quietly for a year would've been worse than one awkward five minutes." — carrying the post's one concrete number ("five minutes"). Draft dropped it entirely and substituted a vaguer negation sentence in its place ("Silent assumptions are the actual risk here, not the ratio."), which also duplicates the flare beat's licensed negation-contrast device elsewhere in the same post. Gate it; the fix is to reinsert the outline's own comparison sentence (verbatim or near-verbatim) rather than let a negation-shape placeholder stand in for a dropped concrete detail.

## Keyword stuffed into an existing metaphor
2026-07-15 (draft mode, "dark-dashboard-design") — when an outline beat's `keyword` is a multi-word SEO phrase ("analytics dashboard UI design"), watch for the drafter stacking it as a compound-noun modifier inside an existing metaphor sentence — e.g. "The charts joined that same analytics dashboard UI design contract the tiles already signed" (keyword wedged between "same" and "contract," breaking the metaphor into an unparseable triple-stacked noun pile). Reads as keyword-stuffing, an AI/SEO tell, not Scout's voice. Gate it; fix by giving the keyword its own short sentence adjacent to the metaphor rather than stuffing it inside the metaphor's clause (e.g. "The charts joined the same contract the tiles already signed: ... . That's the analytics dashboard UI design rule for the whole page, tiles and charts alike."). A milder version (keyword swapped into an ourTake noun phrase, e.g. "the standard analytics dashboard UI design was never built to keep it") reads merely clunky, not broken — elevation only; gate threshold is whether the insertion breaks parseability/metaphor, not just grace. Follow-up 2026-07-15: gate-worthy version fixed correctly next draft; the milder parenthetical version persisted across drafts and stays elevation-only, drafter doesn't need to chase it.

## Tacked-on justification clause after a strongly-landed opinion
2026-07-15 (draft mode, "writing-alt-text-seo-accessibility") — when `gateGuidance` explicitly instructs landing a comparison/opinion and stopping ("resist the urge to explain... let the reader hear it"), watch for the drafter appending a trailing ", because X" clause that re-justifies the point instead of letting it stand — e.g. "...gives the crawler honest words about an actual image, because that's what was already true of the picture." The added clause isn't a classic hedge word, but it's the same AI tell: explaining a point the reader just heard land, rather than trusting it. Gate it when the outline explicitly calls for a clean stop; cut the trailing clause back to the sentence's natural end.

## SEO keyword phrase used as the sentence's grammatical subject
2026-07-15 (draft mode, "ai-automation-stack") — distinct from the "keyword stuffed into an existing metaphor" pattern (that one breaks parseability). This one stays grammatically fine and still reads off-voice: the drafter opens a sentence with the secondary-keyword phrase itself as subject, e.g. "Business automation with AI agents holds up when the work gets split into narrow stages with hard boundaries..." and "Guidance aimed at solopreneur automation with AI finds that narrow, single-purpose tools consistently beat broad do-everything platforms..." Both parse fine but read like SEO landing-page copy, not a person stating an opinion — no human says "guidance aimed at X finds that Y" out loud. Gate it; fix by moving the keyword out of subject position, e.g. trailing "that's what X looks like when it holds up" or "One guide on X backs this up: Y."
Recurred a third time 2026-07-15 (later draft, same post), in a new spot: "At the reporting layer, solopreneur automation with AI looks like a system willing to say NOT YET out loud, on a post I wrote myself." — same subject-position pattern, this time in the measurement section rather than the intro/payoff beats. Notably the SAME draft correctly applied the "One guide on X backs this up: Y" fix elsewhere ("One guide aimed at solopreneur automation with AI backs this up from outside this one project: ...") — the fix isn't sticking uniformly across every occurrence of this keyword in one draft, so check every sentence containing this exact secondary keyword, not just the previously-flagged spots.
Recurred 2026-07-16 (draft mode, "dividing-a-company-that-makes-no-money") as a bare copula template — "[keyword phrase] is [predicate]." — reused three separate times in one draft, each time with a different secondary keyword swapped into subject position: "splitting equity with a friend is one of the anxieties founders quietly Google and almost never bring up out loud" (hook beat — this exact sentence had already been gated once at the outline stage and drafter reintroduced it), "A cofounder equity split is easy to agree on when no one's ego or rent is riding on it" (turn beat), and "Avoiding cofounder conflict is worth more than getting the ratio exactly right" (proof beat). Confirms the pattern isn't confined to a single sentence template ("X holds up when...", "Guidance aimed at X finds...") — the bare "[keyword] is [predicate]" copula is the same tell and just as gate-worthy. Also confirms an outline-stage fix does not reliably survive into the draft — recheck the exact flagged sentence again in draft mode, don't assume the outline fix stuck. Contrast case, same draft: "A 50/50 cofounder split chosen to dodge a conversation just reschedules that conversation for a worse time, with more riding on it" — keyword is grammatical subject too, but the verb is active ("reschedules," not "is") and the modifying clause carries real argumentative content; this reads as a held opinion, not landing-page copy — left as pass, not flagged. The line between gate and pass is the copula ("is") plus generic-template feel, not bare subject-position alone.
Follow-up 2026-07-16, next draft of the same post: all three prior instances fixed and held clean — hook now reads "a lot of people quietly Google how to split equity with a friend" (object position), turn beat reads "It's easy to agree on a cofounder equity split when..." (dummy "It" subject), proof beat reads "Getting the ratio exactly right matters less than avoiding cofounder conflict altogether" (keyword in comparative object position). Confirms all three prescribed fixes stuck. But a FOURTH, previously-unflagged instance appeared with a different keyword in the same draft: "This is founder equity before revenue: an early principle, written down on purpose." (context beat, keyword "founder equity before revenue" as the bare copula's predicate nominative). Same tell, different keyword, different beat — this pattern isn't self-limiting to the keywords already caught; check every beat's own `keyword` field against its own sentences on every draft, not just the previously-flagged spots.

## Bare-definitional verb family extends beyond "is"
2026-07-16 (draft mode, "rate-limiting-an-llm-so-a-stranger-cant-run-up-my-bill") — the keyword-as-subject gate isn't limited to the copula "is"; a defining verb like "means" reads the same way. Draft opened a section: "Public chatbot cost control, done this way, means stacking six unclever limits instead of trusting one clever one." — keyword subject + defining verb ("X, done this way, means Y") is the same landing-page-copy tell as "X is Y". Fix: move the keyword out of subject position, e.g. "Doing public chatbot cost control this way means stacking six unclever limits instead of trusting one clever one." (gerund-phrase subject, keyword becomes object of "doing"). Watch for "means", "looks like", "amounts to" alongside "is"/"holds up when"/"finds that" as members of this family.

## Mid-sentence attribution-disambiguation as hedge
2026-07-15 (draft mode, "grill-me-what-an-auditor-sees") — hedge-theater sub-pattern distinct from "it's worth noting"/"arguably": a mid-sentence attribution-disambiguation clause inserted to preempt a fact-check objection, e.g. "A skill called 'Find-Skills,' nothing to do with Mitiga beyond being the example their research picked, pulled over 200,000 downloads..." Accurate and probably necessary, but embedded as a qualifying aside it reads like a defensive fact-checker's correction, not Scout's direct voice. Gate it; fix by moving the disambiguation into a tight parenthetical aside ("(not Mitiga's own skill, just the example their research picked)") rather than a comma-qualifier chain, so the sentence still reads as a flat, confident claim. Follow-up 2026-07-15: fixed exactly as prescribed next draft — confirms the parenthetical-aside fix holds.
