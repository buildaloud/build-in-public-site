# Outline hygiene

- **2026-07-15** — When one beat's `facts`/`gateGuidance` explicitly hands ownership of a detail to a *later* named beat (e.g. "the border treatment itself belongs to the signature-marks beat later"), check that the earlier beat's `intendedBeat` prose actually respects that handoff — it often still spells the deferred detail out in full anyway, so both beats end up fully re-describing the same fact (e.g. a color's exact border spec told twice). Flag the earlier beat's intendedBeat for trimming to a mention, not the later beat.

- **2026-07-15** — When `gateGuidance` instructs "protect this closing line as a candidate line-that-lands, render it verbatim," check that line actually appears somewhere in that beat's `intendedBeat`/`ourTake` text. Outline revisions sometimes cut the line from the prose but leave the protect-verbatim instruction pointing at nothing — the drafter then has no concrete sentence to anchor to. Fix by folding the missing line back into `ourTake` (cheapest) rather than flagging the mismatch alone.

- **2026-07-15** — Cross-check any concrete number (image count, agent count, percentage) that gets restated in a closing/payoff/CTA beat against the same number established earlier in the outline (hook, opening beat, a middle "show-the-work" beat). Outlines sometimes drift a count between beats during revision (e.g. hook and a middle beat both say "17 hero images" but the closing beat's "resolve the hook" line says "fifteen images later") — this reads as a real inconsistency to a reader and undercuts the payoff beat specifically, so it's squarely an impact-axis catch even though it's also a fact-check-shaped error.

- **2026-07-15** — When a beat's own `gateGuidance` explicitly forbids an authorial move (e.g. "resist the urge to explain the contrast after stating it; let the reader hear it" on a beat built around two quoted strings sitting side by side), check that the same beat's `intendedBeat` doesn't script exactly that forbidden move in its own closing sentence. Outlines sometimes contain this self-contradiction — gateGuidance says don't explain, intendedBeat's last clause explains anyway — and it should be resolved by trimming the intendedBeat's explanatory tail, not by flagging gateGuidance.

- **2026-07-15** (ai-automation-stack outline) — An outline revision pass can leave a leftover *editorial self-instruction* sitting inside a `facts` entry's prose (e.g. "...one setup command saved for the close. Drop the install-command clause from this beat's facts list too, so order 13 is the only place the setup command actually appears.") — a note-to-self about a prior edit that was never stripped out. If left in, the drafter could render it as literal, nonsensical prose. Check every `facts` entry for a stray meta/instructional clause (imperative voice addressed to the outline-writer, not a claim about the world) and flag it for deletion.
