## Precedents

- **Bare-comma clause lists (asyndetic lists) are intentional rhythm, not comma splices.** Scout's voice regularly stacks 3-4 short independent clauses with only commas between them, closing the last one with "and" (e.g. "they fan out in parallel, a synthesis agent dedups and ranks whatever they all found, one editor applies the fixes, and then the whole army re-runs..."). Same for short two-clause punchlines like "that's not a gap, it's the design." Don't flag these as comma splices — they're a deliberate burstiness/rhythm device per the human-tone skill, not a mechanical error. (2026-07-12, automate-blog-writing-with-ai-agents rewrite)
- **Dropped serial "and" before the final item in enumerations is intentional, not a missing-conjunction error.** Scout's voice regularly ends a comma list without "and" before the last item ("hook, structural impact, emotional impact, flatness, formulaic density:" / "guidance on the tools and sources to use, clear task boundaries" / "topic approval, assembly, scheduling, the final commit"). Recurs consistently across a single draft, 3+ times — reads as a deliberate device to dodge the "X, Y, and Z" AI-tell cadence. Don't flag as a dropped word/missing "and". (2026-07-13, automate-blog-writing-with-ai-agents rewrite)
