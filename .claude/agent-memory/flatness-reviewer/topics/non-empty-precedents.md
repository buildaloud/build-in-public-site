# NOT empty — confirmed valid patterns (do not flag)

### hook-bookend (2026-07-15)
A closing CTA beat that bookends the hook by literally restating the hook's specific numbers (e.g. "the same twelve stages, the same one sign-off") is intentional structure for a `how-i-built-x`-formula post, not the mid-post accidental-restatement pattern (see `restatement-and-throat-clear.md#callback-restatement`). If the outline's `ourTake` for the CTA/closing beat explicitly contains that restatement verbatim (resolving the hook is the beat's stated `goal`), it's earned payoff, not filler — only gate restatements that aren't outline-mandated bookends.

### general-principle-closer (2026-07-15)
A short generalizing sentence that follows two concrete named examples and states the general rule they both instantiate (e.g. "The fact-checker files only fact findings, and the overclaim detector only hunts claims we can't back up. Neither one gets an opinion about the other's job.") carries real scope information — it tells the reader the rule applies beyond just the two named examples. Specific-example-then-general-principle is a valid move, not an echo, especially when it's the outline's stated `ourTake`.

### outline-mandated ourTake / intendedBeat text
When a beat's drafted prose matches the outline's stated `ourTake` OR `intendedBeat` closely (near-verbatim or exact), that structure is exempt from flatness scrutiny even if it would otherwise look like two sentences restating each other — the outline itself mandated the shape. This covers short emphatic paired sentences too (e.g. "None of this is signed. Nothing legal happened here.") when the outline's `intendedBeat` text pairs them the same way — it's a deliberate staccato-punch device, not accidental restatement. Only sentences the drafter added around/beyond the protected outline text are fair game (see `restatement-and-throat-clear.md#protected-clause-scope`).

### decision-log cheap/free motif (2026-07-16)
A `decision-log`-formula outline where nearly every beat's `ourTake` returns to the same cost/timing motif (e.g. "do it while it's free/cheap, not after it's expensive") is intentional thematic threading, not restatement bloat — each beat earns the motif with a different concrete angle (hook states it, turn beat contrasts it, payoff/CTA beats resolve it). Don't gate the theme's recurrence across beats; only gate an actual duplicated clause sitting inside one beat's own text.
