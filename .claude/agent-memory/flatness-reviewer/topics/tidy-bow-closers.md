# Tidy-bow closers & punch-fragment tails

### Core pattern (2026-07-15)
A short "bookend" closer sentence (3-5 words, e.g. "Same memory, new engine.") tacked onto the end of a paragraph that already stated its content in full is the "tidy-bow closer" pattern named in the agent spec — gate and delete outright, don't try to preserve it. Also gate a throat-clear pair where two consecutive sentences both announce "external evidence backs this up" before any evidence appears (e.g. "External research backs the same shape from outside this one project. One guide ... backs this up: ...") — cut the first, fold its unique detail ("from outside this one project") into the surviving sentence. Confirmed: a persistent tidy-bow closer flagged in a prior round ("Same memory, new engine.") can survive into the next drafting round unchanged — re-check for it every round, don't assume a prior gate finding auto-fixes.

Also: a `gateGuidance` instruction to "give this confession its own paragraph break" is a structure note (flag as elevation if ignored), but a closing sentence in that same run that purely restates a list just given (e.g. "Three exceptions, and I can name every one of them." after the three were just named) is a separate, gate-level tidy-bow finding.
