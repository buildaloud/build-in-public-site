# Keyword-label tic

Recurring drafter tic across multiple posts (`ai-automation-stack`, `automate-blog-publishing-schedule`, `hired-a-team-of-specialists`, and the model-routing "no exceptions" tic is the same family — see `misc-catches.md#universality-tail`): a bare "That's what X looks like" / "That is [secondary keyword] running this blog" / "This is [keyword] applied to Y" label sentence gets tacked onto a paragraph right after the real content, purely to land a secondary keyword, adding zero new fact.

**The test:** does the sentence stand alone (period on both sides, zero new fact) vs. is it colon/em-dash-joined to a clause carrying real new content?

- **Gate** isolated stand-alone labels, e.g.:
  - "Business automation with AI agents, done right, looks exactly like that."
  - "Every one of those twelve stages is a discrete link in the AI agent workflow automation running this blog."
  - "Match the tool to the job, every time: AI agent workflow automation, applied to compute instead of judgment calls." (has a colon but BOTH sides are labels — still gate)
  - "That's what multi-agent orchestration is supposed to produce." (`hired-a-team-of-specialists`, stood alone between a setup sentence and the real content)
  - "That's what auto-publish blog posts tooling is supposed to feel like: safe by default, and only mutating anything once I say so." (`automate-blog-publishing-schedule` — colon-joined but BOTH clauses just re-say "dry-run by default" + "nothing touches disk until --apply" from two sentences earlier)
- **Pass** (leave as elevation at most) the sanctioned merged form where one side carries genuine new information:
  - "That hand-off is the AI agent workflow automation happening here: other agents keep checking the finished draft against that same rubric, round after round." (round-after-round mechanism is new)
  - "...with no model call anywhere in the path: automating a business with AI, at its most literal." (real claim precedes the colon)
  - "...instead of a single verdict — that's what multi-agent orchestration is supposed to produce." (label spliced onto the END of the concrete sentence via em-dash, not standing alone)
  - "That's what running Claude Code subagents instead of one prompt looks like, and the only cost is the time it takes to write the mandate." (label clause joined by "and" to a second clause carrying a real new claim — cost = time to write the mandate — in the SAME sentence)

**Fix pattern:** never delete the keyword outright (SEO needs it in the beat); merge it into the adjacent concrete sentence via colon/em-dash so the keyword lands attached to real information instead of standing alone as a label. For isolated labels at the front of a beat, move them to splice onto the end of the concrete sentence that follows instead.

A comma-tail restatement variant of the same family also recurs: "...just publishes on its own date, no scheduler involved at all." — the tail restates "doesn't need any of that machinery" stated one sentence earlier; cut back to the plain sentence.
