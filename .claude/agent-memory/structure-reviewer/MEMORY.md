## Precedents

- 2026-07-12 (automate-blog-writing-with-ai-agents rewrite): outline `gateGuidance` sometimes locks an exact phrase/sentence verbatim (e.g. "I wrote this pipeline up once already. By the time some of you read it, it was already the old version."). When a locked quote creates an opener echo with a nearby sentence (e.g. two "By the time" openers in one paragraph), don't flag it as opener-sameness — it's mandated content, not a rhythm slip. Only flag echoes that aren't protected by an explicit locked-quote instruction.
- 2026-07-14 (automate-blog-writing-with-ai-agents rewrite): outline `gateGuidance` can explicitly demand a MERGE, not a split — e.g. the token-bill beat's guidance said to land the cost admission and the 4x/15x figures "in one breath," but the draft split them into two clean, well-formed sentences. A technically fine short sentence can still be a structure finding if a beat's gateGuidance wants it fused with its neighbor for pacing. Check gateGuidance for merge instructions, not just split/variety cues, before clearing a paragraph.
- 2026-07-15 (dark-dashboard-design draft): when several separate outline beats each protect (near-verbatim, via `ourTake`) a sentence built on the same syntactic pattern — e.g. "[imperative clause] and [result clause]" with no comma — don't flag the recurring construction as a document-level rhythm tic. Each instance is independently outline-mandated inside its own beat, not an echo the drafter introduced; only flag an instance of that pattern if it appears in prose that ISN'T traceable to a protected `ourTake`/`intendedBeat` line. Same logic extends short anaphora runs explicitly written into `intendedBeat` (e.g. "It reports altitude. It reports fuel level.") — those are a mandated rhetorical device, not opener-sameness.
- 2026-07-15 (grill-me security-audit rewrite): a bulleted findings/spec list where every item opens with the same subject ("It writes files... It shells out... It makes network calls... It chains high-impact steps...") is NOT opener-sameness — bullets read as a parallel spec/checklist, not sequential prose, and consistent parallelism there aids scannability. Only flag same-opener runs inside actual prose paragraphs, never inside bulleted enumerations of findings/scores/definitions.
- 2026-07-15 (design-system-with-css-variables rewrite): recurring "That's [phrase]:" / "That's [phrase], [explanation]" naming sentences scattered across sections (e.g. "That's the entire design system with CSS variables...", "That's CSS custom properties theming doing its most literal job...", "That's terminal aesthetic web design, cashed out in two habits...") are NOT a document-level rhythm tic when each instance anchors that beat's assigned target/secondary keyword per the outline. It's an intentional SEO keyword-tagging device, not drafting laziness — don't flag it as opener/construction echo across sections.
- 2026-07-15 (design-system-with-css-variables rewrite): when a beat's outline `gateGuidance` explicitly says something like "keep it as a calm admission, not a punch-fragment run," don't push for fragment-based burstiness in that beat even if its paragraph reads as a run of same-length (18-25 word) sentences with no short fragment breaking it up. The outline is intentionally asking for steady, sustained prose there, not choppy variety — deciding tone/rhythm blend is in scope for the outline's beat guidance, and it overrides the general burstiness default for that one paragraph.
- 2026-07-15 (ai-automation-stack rewrite): when an outline `gateGuidance` locks a rhetorical device verbatim (e.g. a negative-parallelism flare line: "doesn't owe me X; it owes me Y, and...") and the draft flattens it by dropping the negating clause, that IS an in-scope structure finding, not just a fact/wordsmith one — the drafter broke the sentence's shape (lost the two-beat call-and-response), which is squarely rhythm/construction. Flag it as a restore-verbatim structure edit whenever the loss is a shape/device loss, not merely a word swap.
- 2026-07-16 (teaching-a-robot-to-balance-my-game rewrite): when an `intendedBeat` explicitly frames a sentence as "in one breath" (a single dense colon/comma-chained sentence enumerating multiple clauses), don't flag the resulting long multi-clause sentence as a run-on even if it stacks 3 clauses via commas — it's a deliberate compression device the outline asked for, not an unplanned overpack. Only flag a beat's "one breath" sentence if it's also genuinely garden-path/hard-to-parse (subject-verb separated by a long relative clause), not merely long.
