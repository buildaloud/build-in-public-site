# Outline-builder — precedent ledger

Read FIRST before building any outline; append ONE dated line only for a
durable, recurring lesson. Keep under 40 lines; dedupe; correct in place.

## Known recurring outline-stage gate findings (seeded 2026-07-15)
- 2026-07-15 — Negative parallelism in ourTake/intendedBeat/gateGuidance fields
  propagates verbatim into drafts. State the take directly (pitfalls §1).
- 2026-07-15 — Runs of 3+ consecutive beats with the same paragraphFormula
  (esp. claim-then-evidence) get gated every time. Vary the shapes.
- 2026-07-15 — Every factual beat needs a source or it costs a round. The
  fact-checker will re-derive counts (stage lists, reviewer counts) from the
  canonical facts file — copy them from there, never from memory.
- 2026-07-15 — Dramatic-sequencing hooks ("X happens before Y") are capped at
  ONE per post and only when sequencing IS the point (pitfalls §7).
- 2026-07-15 — On rewrites, the EXISTING body's rhetoric (tricolons, "whole
  point/problem" shapes, neg-parallel headings) gets grandfathered into the new
  outline verbatim. Re-screen every inherited line against the pitfalls file;
  facts carry over, crutches don't.
- 2026-07-15 — Inherited closings are the top bookend violation on rewrites:
  rebuild the close from pitfalls §8 (resolve THIS post's hook, link its own
  implementation, one CTA), and frame any post-pubDate artifact in plain
  present tense with no shipping-date claim.
- 2026-07-15 — On rewrites, re-verify every inherited hex, percentage, and
  pixel count against the actual source file (global.css / facts.md): the CSS
  post's old body carried wrong text hexes, a wrong color-mix percentage, and
  token names that never existed. "Previously fact-checked" bodies still drift.
- 2026-07-15 — Mission-pinned "pipeline update" claims can contradict the live repo: verify against git log + tickets before outlining. (Resolved same day: swap commit 4e445c1 landed 2026-07-15, so the npm-package claim is now TRUE even though TD-0038's status field still reads open — ticket metadata lags commits; trust the log, and keep swap-date prose vague since mission said 07-14 vs commit 07-15.)
- 2026-07-15 — Cross-link tense goes stale in BOTH directions on rewrites: a
  sibling post framed as "coming" in the source body may now publish BEFORE
  this post's pubDate (ai-automation-stack 07-19 vs scheduler post 07-20) —
  check every inherited link's tense against real pubDates, not just
  future-dated targets.
- 2026-07-16 — Personal-story rewrites have no canonical facts file: the pinned
  source body IS the fact base, so cite the live post URL on first-person beats
  and add zero new business specifics (percentages, names, legal/vesting terms)
  beyond what that body already made public.
- 2026-07-16 — Product/game rewrites: facts.md has no entries for in-game
  numbers (HP_SCALING_BASE, sim:tune); the pinned body is the fact base — cite
  the live artifact + sibling build-log URL, and don't import the mission's
  content-pipeline boilerplate beats into posts that aren't about the pipeline.
